Objective:
Design an interactive financial dashboard for business stakeholders using Tableau and Excel. The goal is to visualize company performance across key metrics like Sales, Profit, and Market Capitalization, and provide actionable insights through interactivity.

Tools Used:
Tableau
Microsoft Excel

Dataset:
Financial-Analytics-data1.csv (Kaggle financial dataset)

Key Steps Performed:
Data cleaning in Excel (handled missing values, formatted currency).

Imported cleaned data into Tableau.

Created KPI cards for Total Sales, Average Sales, and Market Cap.

Built visual sheets:

Top Companies by Sales (Bar Chart)

Market Cap vs Sales (Scatter Plot)

Category Breakdown (Treemap / Stacked Bar)

Sales Distribution (Histogram / Box Plot)

Detailed Data Table (for drill-down view)

Combined all sheets into one interactive dashboard.

Added slicers, filters, and a consistent color theme.

Dashboard Features:

Interactive filters (Market Cap Category, Sales Category)

KPI summary cards

Dynamic tooltips for company-level insights

Navigation buttons between views

Insights Derived:

Top 5 companies contribute majority of Market Cap.

Large Cap firms dominate both Sales and Market performance.

Clear correlation between Sales and Market Cap observed in scatter plot.

Deliverables:

Financial_Dashboard.twb or .twbx — Tableau dashboard file

Financial_Insights.xlsx — Excel file used for cleaning and prep

README.md — Documentation (this file)

Conclusion:
This project demonstrates practical data visualization skills in Tableau, transforming raw financial data into business-ready dashboards for decision-making and executive review.
